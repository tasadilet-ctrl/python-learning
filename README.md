# Python Learning

Early Python fundamentals exercises — day-by-day practice building up from basics to small OOP programs.

| File | Topic |
|---|---|
| [`day1.py`](day1.py) | Input/output, arithmetic, a basic calculator |
| [`day1_part2.py`](day1_part2.py) | Conditionals — even/odd checks, grade thresholds |
| [`day2.py`](day2.py) | Functions, booleans, control flow |
| [`day3.py`](day3.py) | File I/O — reading and writing text files |
| [`day4.py`](day4.py) | Classes — `Student` and `Course`, enrollment logic |
| [`day.py`](day.py) | Inheritance — `Pet` base class with `Dog`/`Cat` subclasses |
| [`main.py`](main.py) / [`student_utils.py`](student_utils.py) / [`students/`](students) | Splitting a student-roster read/write utility into its own module |

`students.txt` / `day3.txt` are sample output produced by running the corresponding scripts.
